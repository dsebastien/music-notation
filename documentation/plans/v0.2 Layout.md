# v0.2: layout

Goal: several diagrams per block (#1), orientation and left-handed diagrams (#2), for Music Practice 0.3 (issue #32 there).

## Several diagrams in one block (#1)

- `chord`, `keyboard` and `fretboard` blocks split on lines that are only `---` (3 or more dashes). `chords` (ChordPro) never splits. A block without a separator renders as before.
- **Shared settings**: the first part is a header when it has no shorthand line and every key is shareable. Shareable everywhere: `orientation`, `hand`, `labels`; `chord` adds `instrument`, `tuning`; `keyboard` adds `range`; `fretboard` adds `tuning`, `frets`. Header only: `columns: N` (1 to 12).
- **Precedence**: the part's key, then the header's, then the render options' defaults, then the language default.
- **Layout**: a row that wraps (flex), or an N-column grid with `columns`. Same drawing scale for every diagram, aligned at the top.
- **Errors**: a part with a mistake shows its message in its own cell; the others draw. `renderBlock` returns `ok: false` with every part's message (Publish keeps the source visible, as for any error).
- **Limits**: empty parts are skipped; a header with no diagram is an error; at most 32 parts.

## Orientation and hand (#2)

- `orientation: vertical | horizontal`. Defaults: chord diagrams vertical, keyboards and fretboards horizontal.
    - Horizontal chord diagram: strings horizontal, high string on top (as tabs and the fretboard), nut on the left, open and muted marks left of the nut, the base fret under the first fret space.
    - Vertical fretboard: nut on top, low string on the left (as a chord diagram), string names above the nut, fret numbers on the left.
    - Vertical keyboard: low notes at the bottom, black keys on the left (piano roll). Piano chords follow.
- `hand: left | right`: mirrors guitar diagrams and fretboards. Keyboards ignore it.
- Text is never rotated or mirrored: renderers map their own coordinates to x/y.
- Render options: `orientation` per language and `hand`, used when a block doesn't say. The Publish bundle reads `window.musicNotationOptions` when the page sets it before loading.
