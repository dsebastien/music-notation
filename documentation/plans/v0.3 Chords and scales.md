# v0.3: chords and scales

Goal: chord names in words and chords recognized from their notes (#3), scales and modes that are easier to see and learn (#4), and blocks drawn from a note's properties, for Music Practice 0.4 (issues #33, #34 there) and Obsidian Publish. Tabs and scores move to 0.4.

## Chords (#3)

- Chord names in words wherever a symbol is accepted (`symbol:`, `name:`, the shorthand line): `A Major`, `a minor`, `F Sharp Minor 7`, `B Flat 7`, `C Major over G`, `E 5`, `D Sus4`; any case, `♯`/`♭`/`#`/`b`. The reverse of `parseChord().name` (round trip); the words stay the title. `parseChordName(text)`.
- Unknown names suggest the closest ones ("try A, Am, A7 or A Major").
- Chords recognized from `frets` (tuning-aware) or `pitches` when no symbol is given: name and root marks. Ambiguous notes: root position first, then the simplest quality; `symbol:` always wins. `detectChord(...)` returns the symbol and the other readings.

## Scales and modes (#4)

- Scale names: tonal's, plus the common ones as written (`Natural minor`, `Major pentatonic`, `Blues`, `Whole tone`…), any case. A scale without a root: "Add a root note: C lydian". The guide lists the known scales.
- `highlight: characteristic` (default for modes; `none` turns it off) marks the defining notes in a third color (lydian #4, dorian 6, mixolydian b7, phrygian b2, locrian b5, aeolian b6, blues b5); `highlight: b5 7` marks any intervals.
- `compare: major` (or `C major`): notes that differ from the parent outlined, the parent's missing notes as faint ghost dots.
- Fretboard positions: `position: 1..5` (boxes for 5-note scales, CAGED windows for 7-note scales), `shape: C|A|G|E|D` (a CAGED shape by name), `shape: 3nps` with `position: 1..7`. The fret range follows the position. Tests check the shapes against standard charts.
- `modes: C major`: the seven modes in a row (0.2 rows), each with its characteristic note.
- Keyboard `fingering:` for scales: one finger per note of one octave.

## Blocks from properties

- `blockFromProperties(language, properties, { names, instrument })`: the source of a `chord`, `fretboard` or `keyboard` block from a note's properties (chord symbol, frets, fingers, position; piano pitches, fingering, inversion; scale root, type, shape, fingerings). Default names follow Music Practice and the Obsidian Starter Kit; hosts pass their own. Instrument from the option, else from tags (a `piano` segment), else guitar.
- `renderBlock` option `properties`: an empty block draws from them. The Publish bundle reads `window.musicNotationOptions.properties` (a function returning the page's properties).
