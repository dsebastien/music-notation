## App controls on timed play bars (#77, branch lib-hooks)

- New `play` option `timedBar(bar)` (`PlayOptions`, type `TimedBar` exported): called for each strum, picking, progression and chart bar with its kind, element, drawing, compound flag, `tempo()`, `onTempo(listener)` and `add(control)`. One helper (`src/playback/app-bar.ts`, `handToApp`) serves both bar builders (`timedBarFor`, `progressionBarFor`); each bar's stop function also frees what the hook returned. App controls go in a `.mn-play-app` slot, last in the bar (and in the focus order), with the bar's button styles.
- For Music Practice #88: in a learning note, `timedBar: (bar) => { if (bar.kind !== 'strum' && bar.kind !== 'picking') return; const b = createEl('button', …); b.onclick = () => openSetBpm(bar.tempo()); bar.add(b) }`. `tempo()` counts the beat the pattern counts, the same beat the note's `bpm_current` is written in as `tempo:`.
- Specs (`bar-hooks.spec.ts`, 7; 6 failed before, the "no hook" one passed): kind and tempo for each bar kind, tempo changes and unsubscribing, compound time, the slot and focus order, the cleanup on destroy, a throwing hook.
