# 2026-10-28

## Done

- Repo created with the plugin template's tooling (Bun, TS, ESLint type-checked, Prettier, commitlint, config-based hooks), adapted to a library: no Obsidian rules, scope `lib`, npm entry points.
- Theory: chord symbol parsing moved from the Music Practice plugin; pitch classes, scientific pitch, transposition with key-aware spelling, note sets (tonal) with degrees and musician-style interval labels.
- Blocks: `chord` (guitar diagram with barres, base fret, root marks, tunings; piano chords from symbols or pitches, fingering), `keyboard`, `fretboard` (tunings, open strings, inlays), `chords` (ChordPro subset, sections, transpose).
- Voicings: chords-db lookup (sharps/flats, aliases, slash chords) behind `./voicings`.
- Publish: `renderAll` / `autoRender` (idempotent, MutationObserver, source hidden only on success) and the IIFE bundle (255 KB, most of it voicing data).
- Checked in Obsidian (dark theme) through the bundle: fixed black piano keys following the text color, and interval labels (3m → b3).
- Docs: README, GitHub Pages guide (blocks, Publish, API), business rules, architecture, plans.

## Decisions

- Two steps: 0.1 light blocks (→ Music Practice 0.2), 0.2 alphaTab (→ Music Practice 0.3).
- No ChordPro library: the maintained ones are GPL.
- Voicing data in its own entry point.
- Piano keys keep fixed white/black colors in every theme.

## Adversarial review (before 0.1.0)

20 findings, all fixed:

- ChordPro directive regex could freeze the page (n⁴ backtracking): replaced by a linear parser; test on 5,000-space lines.
- One chord-symbol splitter (`splitChordSymbol`) everywhere: ♯/♭ accepted, `C6/9` isn't a slash chord; chords-db aliases for 6/9 and minor-major 7.
- Unknown symbols with frets render (no root marks) instead of failing; `position` can't be above the lowest fretted note; piano bass matched by pitch.
- Chord degrees are interval numbers (C7 → 1 3 5 7); a shorthand `C4` is one key, not a quartal chord; `labels: fingers` only for piano chords.
- Transpose rounds fractions, ignores NaN; `nameOf` safe for any number.
- Tunings: prototype keys (`constructor`) no longer crash (Map); lowercase `eadgbe` reads six strings.
- Publish: re-renders when the source changes in place or the rendering is removed; a broken edit shows the source again; `stop()` cancels a scheduled pass; the bundle starts once even if loaded twice.
- Packaging: voicing data inlined (chords-db now a dev dependency), so `./voicings` loads in Node; `.js` extensions in relative imports (types work under NodeNext), `typesVersions` and `default` conditions (node10), `*.css` in `sideEffects`; third-party notices in `dist/THIRD_PARTY_LICENSES.md` and a bundle banner.
- CSS variables also on `.mn-svg` / `.mn-chart` (standalone renderers); lyrics wrap; root color darkened for white labels.
- `parseFingers` comment fixed, `parseKeyRange` refuses 3 parts, guide updated.
